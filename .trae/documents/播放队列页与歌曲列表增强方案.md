# 播放队列页与歌曲列表增强方案

## 背景

用户提出三项需求：

1. 播放页面新增"播放列表"按钮，进入播放队列页显示当前正在播放的队列
2. 歌曲列表项右侧增加"更多操作"按钮，弹出"下一首播放"、"添加到播放列表"等菜单
3. 歌曲列表顶部增加"播放全部"按钮（仅已加载完整的列表页）

底层 `AudioPlayerNotifier` 已具备完整队列操作 API（`load / addTracksAtFirst / addTracks / jumpToTrack / removeTrack`），但 UI 层未接入。本次主要做 UI 接入 + 响应式分流。

## 关键决策（用户已确认）

* **播放队列页呈现**：移动端全屏 `Navigator.push`，桌面端 `openSheet(position: OverlayPosition.right)` 从右侧滑出，用 `Rx.action` 分流

* **更多操作菜单呈现**：移动端 `openSheet(position: OverlayPosition.bottom)` 从底部弹出，桌面端 `showDropdown` + `DropdownMenu` 在按钮旁弹出

* **"播放全部"按钮应用范围**：仅 `playlist_detail_page.dart`（项目当前唯一已加载完整的歌曲列表详情页；排行榜歌曲内嵌在 `home_page.dart`、专辑详情页不存在，本次不接入）

## 复用的现有 API

* `lib/modules/audio_player/providers/audio_player.dart`

  * `load(List<Song>, {int initialIndex = 0, bool autoPlay = false})` — 播放全部

  * `addTracksAtFirst(Iterable<Song>)` — 下一首播放

  * `addTracks(Iterable<Song>)` — 添加到播放列表/队列

  * `jumpToTrack(Song)` — 队列项点击跳转

  * `removeTrack(String trackId)` — 从队列移除

* `lib/ui/music/song_list.dart` — 通用 `SongList` 组件（需扩展 `showMoreActions`）

* `lib/ui/music/widgets/play_pause_button.dart` — 已有播放/暂停切换

* `lib/core/rx.dart` — `Rx.action(context, mobile: ..., tablet: ...)` 响应式分流

* shadcn\_flutter：`openSheet` / `showDropdown` / `DropdownMenu` / `MenuItem`

## 一、新增文件

### 1. `lib/ui/music/widgets/song_more_actions_button.dart`

* `class SongMoreActionsButton extends HookConsumerWidget`

  * 字段：`final Song song; final VoidCallback? onRemoveFromQueue;`

  * 按钮：`IconButton.text(icon: Icon(Icons.more_vert, size: 18))`

  * 点击调用 `_openActions(context, ref)` 用 `Rx.action` 分流：

    * 移动端：`openSheet(position: OverlayPosition.bottom, draggable: true, builder: SongMoreActionsSheet)`

    * 桌面端：`showDropdown(builder: DropdownMenu(children: menuItems))`

* 共享内容组件 `SongMoreActionsContent({required Song song, VoidCallback? onRemoveFromQueue, VoidCallback? onClose})`

  * 菜单项：

    1. 下一首播放 → `ref.read(audioPlayerProvider.notifier).addTracksAtFirst([song])` + `Rx.toast.success('已添加到下一首')`
    2. 添加到播放列表 → `addTracks([song])` + `Rx.toast.success('已添加到播放列表')`
    3. 从列表移除 → `onRemoveFromQueue?.call()` + `removeTrack(song.id)` + `Rx.toast.success('已移除')`（仅当 `onRemoveFromQueue != null`，即仅播放队列页显示）

  * 移动端用 `Column[PrimaryButton.title(...)...]` 内嵌于 Sheet

  * 桌面端用 `DropdownMenu(children: [MenuItem(title:, leading:, onTap: ...)])`

### 2. `lib/ui/music/widgets/play_all_button.dart`

* `class PlayAllButton extends HookConsumerWidget`

  * 字段：`final List<Song> songs; final int initialIndex; final String? label;`

  * `build`：`PrimaryButton.icon(icon: Icon(Icons.play_arrow), child: Text(label ?? '播放全部'), onPressed: songs.isEmpty ? null : _playAll)`

  * `_playAll`：`ref.read(audioPlayerProvider.notifier).load(songs, initialIndex: initialIndex, autoPlay: true)` + `Rx.toast.success('开始播放：${songs.length} 首')`

### 3. `lib/ui/player/widgets/play_queue_content.dart`

* `class PlayQueueContent extends HookConsumerWidget`

  * 监听 `ref.watch(audioPlayerProvider)` 取 `state.tracks` / `state.activeTrack` / `state.currentIndex` / `state.loopMode` / `state.shuffled`

  * 结构：`Column[ _QueueHeader(songCount, 循环模式 IconButton, 清空 IconButton), Expanded(ListView.builder) ]`

  * 列表项：`Card(child: ListTile(leading: 序号或 equalizer 图标(高亮), title: song.name, subtitle: artist · duration, trailing: PlayPauseButton(song:) + SongMoreActionsButton(song:, onRemoveFromQueue: () => notifier.removeTrack(song.id))))`

  * 点击项：`notifier.jumpToTrack(song)` → `audioPlayer.jumpTo(index)`

  * 当前曲目高亮：`activeTrack?.id == song.id` 时 title 用 `colorScheme.primary`，leading 用 `Icons.equalizer`

  * 空队列：`Center(child: Text('播放队列为空'))`

### 4. `lib/ui/player/play_queue_page.dart`

* `@RoutePage() class PlayQueuePage extends HookConsumerWidget`

* 移动端全屏页面：`Scaffold(headers: [AppBar(leading: [返回按钮], title: Text('播放队列'))], child: PlayQueueContent())`

* 桌面端不进入此路由，由 `openSheet` 直接渲染 `PlayQueueContent`

## 三、响应式分流实现

**播放队列入口**（playback\_page.dart）：

```dart
void _openPlayQueue(BuildContext context) {
  Rx.action(
    context,
    mobile: () => context.pushRoute(const PlayQueueRoute()),
    tablet: () => openSheet(
      context: context,
      position: OverlayPosition.right,
      builder: (_) => const SizedBox(width: 360, child: PlayQueueContent()),
    ),
  );
}
```

**更多操作菜单**（song\_more\_actions\_button.dart）：

```dart
void _openActions(BuildContext context, WidgetRef ref) {
  Rx.action(
    context,
    mobile: () => openSheet(
      context: context,
      position: OverlayPosition.bottom,
      draggable: true,
      builder: (_) => SongMoreActionsContent(
        song: song,
        onRemoveFromQueue: onRemoveFromQueue,
        onClose: () => Navigator.of(context).pop(),
      ),
    ),
    tablet: () => showDropdown(
      context: context,
      builder: (_) => DropdownMenu(
        children: _buildMenuItems(context, ref),
      ),
    ),
  );
}
```

## 四、关键交互流程

### 点击"下一首播放"

1. 用户点击歌曲列表项右侧"更多"按钮 → `_openActions`
2. 移动端从底部弹出 Sheet / 桌面端按钮旁弹出 DropdownMenu
3. 点击"下一首播放" → `ref.read(audioPlayerProvider.notifier).addTracksAtFirst([song])`
4. Notifier 内部：将 song 插入到 `currentIndex + 1` 位置
5. `Rx.toast.success('已添加到下一首')`
6. `onClose?.call()` 关闭面板

### 点击"播放全部"

1. 用户在歌单详情 Header 点击"播放全部"
2. `ref.read(audioPlayerProvider.notifier).load(songs, initialIndex: 0, autoPlay: true)`
3. Notifier 调用 `audioPlayer.openPlaylist(songs.asMediaList(), initialIndex: 0, autoPlay: true)` 清空原队列并替换
4. `Rx.toast.success('开始播放：${songs.length} 首')`

### 点击播放队列项

1. 用户点击队列内某项 → `notifier.jumpToTrack(song)` → `audioPlayer.jumpTo(index)`
2. 播放器跳转到该曲目但不一定自动播放（取决于现有 playing 状态）
